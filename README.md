# DMS - سیستم مدیریت شرکت پخش مواد غذایی

نسخه اولیه قابل توسعه برای شرکت پخش مواد غذایی.

## امکانات نسخه فعلی
- ورود آزمایشی مدیر و ویزیتور
- داشبورد مدرن RTL
- مدیریت مشتریان
- مدیریت کالاها
- ثبت و مدیریت سفارش‌ها
- وضعیت سفارش‌ها
- بخش مالی و سود تقریبی
- گزارش‌ها
- تنظیمات ساده
- ذخیره داده‌های نمونه در LocalStorage مرورگر

## کاربران آزمایشی
مدیر:
- username: `admin`
- password: `1234`

ویزیتور:
- username: `visitor`
- password: `1234`

## اجرا
در پوشه پروژه:

```bash
npm install
npm run dev
```

سپس:
`http://localhost:3000`

## نکته مهم
این نسخه عمداً بدون دیتابیس خارجی ساخته شده تا بتوانیم ابتدا ابزار واقعی را روی کامپیوتر تست کنیم.
داده‌ها در LocalStorage ذخیره می‌شوند؛ بنابراین فعلاً فقط در همان مرورگر/دستگاه باقی می‌مانند.

مرحله بعدی پیشنهادی:
1. اتصال Supabase/PostgreSQL
2. احراز هویت واقعی
3. نقش‌ها و دسترسی‌های واقعی
4. همگام‌سازی موبایل و کامپیوتر
5. ثبت فاکتور و حسابداری کامل
6. گزارش‌های حرفه‌ای
